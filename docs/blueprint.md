# **App Name**: ZeitplanPro

## Core Features:

- Current Time Display: Display the current time at the top of the page.
- School Time Indicator: Indicate whether the current time is during school hours (8:00 - 13:00).
- Time to End Tool: If during school hours, use an AI tool to display the remaining time until the end of the school day (13:00).
- Interactive Timetable Display: Display the timetable in a table or tile view, highlighting the current subject.
- Subject Information Modal: On clicking a subject, a modal or pop-up displays additional information (teacher, room, notes, materials link).
- Main Subject Highlighting: Highlight main subjects with a specific visual cue (e.g., bold text, icon).
- Data Storage: The timetable data will be stored in a JSON format.

## Style Guidelines:

- Primary color: Slate blue (#708090) to evoke a sense of calm and focus.
- Background color: Light gray (#F0F8FF), almost white to offer visual clarity.
- Accent color: Soft orange (#E07A5F) for interactive elements and main subject highlights to bring in a friendly and attention-grabbing touch.
- Body and headline font: 'PT Sans' a sans-serif, for clear and accessible typography suitable for all text.
- Use simple, consistent icons to represent main subjects. These icons should be easily recognizable.
- Use a clean, responsive layout optimized for both desktop and mobile views. Prioritize readability.
- Subtle transitions for the subject information modal to create a smooth user experience.
